# Food Assistant (AI Meal Planner & Recipe Keeper)

Una aplicación web progresiva (**PWA**) inteligente inspirada en lo mejor de **Samsung Food (Whisk)**, potenciada con **Google Gemini AI**.

## 🚀 Características Clave
- **📦 Importador Universal de Recetas**: Extrae ingredientes, pasos y fotos desde páginas web y redes sociales (Instagram, TikTok, YouTube).
- **📅 Planificador Semanal Inteligente con Gemini**: Gemini analiza tus recetas guardadas y confecciona automáticamente un menú semanal equilibrado para toda la familia.
- **🛒 Lista de la Compra por Pasillos**: Agrupación automática de ingredientes por pasillo de supermercado (Frutas/Verduras, Carnicería, Lácteos, etc.) con marcado interactivo offline.
- **🍳 Modo Cocina Paso a Paso**: Vista a pantalla completa con texto grande y temporizadores integrados.
- **⚡ 100% Offline (PWA)**: Funciona en cocinas y supermercados sin cobertura mediante IndexedDB y Service Workers.
- **🔒 Privacidad y Control**: Sin feeds sociales innecesarios ni dependencias de hardware propietario.

## 📁 Estructura del Proyecto
- `replica/`: Documentación de ingeniería inversa, arquitectura, sistema de diseño y matriz de paridad (`replica-recon`, `replica-architect`, `replica-design`).
- `replica/recon.md`: Inventario de pantallas y flujos de usuario.
- `replica/architecture.md`: Stack y especificación técnica.
- `replica/schema.sql`: Esquema de datos PostgreSQL / Supabase.
